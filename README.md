# APTUS

Base inicial del módulo de **Órdenes de Trabajo + Materiales**.

## Contenido agregado
- `docs/work-orders-module.md`: diseño funcional y reglas de negocio.
- `database/work_orders.sql`: esquema SQL PostgreSQL con tablas, validaciones y triggers de costo.
- `api/work-orders.http`: ejemplos de endpoints REST para pruebas manuales.

## Nota
El repositorio original estaba vacío (solo `.gitkeep`), por lo que se creó una propuesta implementable para integrarse al código real de la app cuando esté disponible.
